Install the Add-in

Download manifest.xml

Outlook on the Web

  1. Open Outlook on the Web and sign in with your Microsoft account.
  2. Click the gear icon (Settings) → Manage Add-ins.
  3. Scroll to Custom Add-ins → click Add a custom add-in.
  4. Choose Add from URL and paste:
    https://rpapub.github.io/EnfoldedOrichalcum/manifest.xml
  5. Confirm any prompts. The add-in will appear in your toolbar.

Outlook Desktop (Windows)

  1. Download manifest.xml using the button above.
  2. Open Outlook → File → Manage Add-ins.
    (This opens Outlook on the Web — follow the web steps from step 3.)

New Outlook on Windows

  1. Open New Outlook → click … (More apps) in the toolbar.
  2. Select Add apps → Manage your add-ins.
  3. Under Custom Add-ins, choose Add from URL and paste the manifest URL above.

Using the Add-in

  1. Open any email in Outlook.
  2. Click Triage Email in the ribbon.
  3. Fill in the triage fields (Reference is pre-filled from the subject).
  4. Click Copy to Clipboard — a JSON object is copied.
Requirements: A Microsoft account (@outlook.com, @hotmail.com, or Microsoft 365). Gmail/Yahoo accounts added to Outlook desktop do not support add-ins.
