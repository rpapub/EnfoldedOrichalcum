Extension Inspector

Reads and displays every open extension attached to the currently selected email message via Microsoft Graph. Read-only — no data is written.

This add-in has no browser preview because it requires a live Outlook context and a real message with extensions to show anything useful. Install it in Outlook and open any email.

Download manifest.xml

Outlook on the Web

Settings → Manage Add-ins → Custom Add-ins → Add from URL:
https://rpapub.github.io/EnfoldedOrichalcum/addins/extension-inspector/manifest.xml

Graph endpoint used:
GET /v1.0/me/messages/{id}/extensions

Returns all microsoft.graph.openTypeExtension objects on the message. The add-in filters out @odata.* metadata and renders each extension as a key-value card, with nested objects shown as indented sub-tables.
