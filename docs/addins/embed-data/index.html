Install


    
      Download manifest.xml
    

    
Outlook on the Web

    
    
      
  1. Settings (gear) → Manage Add-ins → Custom Add-ins → Add from URL.
    2. 
      
  2. Paste: https://rpapub.github.io/EnfoldedOrichalcum/addins/embed-data/manifest.xml
    3. 
    


    
Outlook Desktop / New Outlook

    
    
      
  1. File → Manage Add-ins (opens Outlook on the Web — follow steps above).
    2. 
    


    
Usage

    
    
      
  1. Open any email → click RPA Embed Data in the ribbon.
    2. 
      
  2. Fill in the fields and click RPA Embed Data.
    3. 
      
  3. On first use a sign-in popup will appear — sign in with your Microsoft account.
    4.
